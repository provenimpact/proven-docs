== Overview

This is a basic example document rendered with **proven-docs**.
It demonstrates standard AsciiDoc features including headings, paragraphs, lists, and inline formatting.

== Highlights

* The CLI converts `.adoc` files to print-ready PDFs
* Mermaid diagrams render as embedded SVGs
* Source code blocks get syntax highlighting
* Everything runs offline — no network required
