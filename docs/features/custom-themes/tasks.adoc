== Overview

Refactor the classified template from a built-in to an example: move template files from `assets/templates/` to `examples/templates/`, remove built-in name resolution and classification colour logic from the theme engine, and move colour styling into the template CSS using `data-classification` attribute selectors. 2 phases, 5 tasks.

== Phase 1: Template Migration and Engine Simplification

Move the classified template to `examples/` and update it for CSS-driven colours. In parallel, remove built-in resolution and colour logic from the theme engine and shared validation.

* [x] TASK-001: Move classified template to examples/ and add CSS colour selectors [parallel]
+
Components:: Example template files (`examples/templates/classified/`)
Stories:: US-004
Specs:: THM-016, THM-017, THM-019, THM-020
Description:: Move `assets/templates/classified/` to `examples/templates/classified/`. In `template.html`: replace inline `{{banner-bg}}` and `{{banner-fg}}` references in the header banner, footer banner, and classification colour cell with CSS class-based styling that will be driven by `data-classification` attribute selectors. Remove the `background-color:{{banner-bg}}; color:{{banner-fg}}` inline styles from the `data-pdf-header` and `data-pdf-footer` div elements and the classification cell `color:{{banner-bg}}`. Instead, add CSS classes (e.g., `classification-banner`) that the theme.css will style. In `theme.css`: add `[data-classification]` attribute selector rules for each level — `[data-classification="PUBLIC"]` (bg: #2e7d32, fg: #ffffff), `[data-classification="INTERNAL"]` (bg: #f57c00, fg: #000000), `[data-classification="CONFIDENTIAL"]` (bg: #c62828, fg: #ffffff), `[data-classification="RESTRICTED"]` (bg: #4a148c, fg: #ffffff). Add a default/fallback rule. Add `body:not([data-classification]) .classification-banner, [data-classification=""] .classification-banner { display: none }` for banner hiding. Note: since header/footer elements use Playwright's headerTemplate (isolated context, no access to page stylesheet), the classification colours for header/footer inline styles must be handled differently — use `data-classification` on the body tag which is already set by the theme engine, and have the template HTML use CSS `<style>` blocks within the header/footer divs referencing the body's `data-classification`.
