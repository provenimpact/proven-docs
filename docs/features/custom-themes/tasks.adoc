== Overview

Custom theme support for PDF output: CSS theme override, HTML template wrapping with Mustache-style attribute substitution, document metadata exposure as data attributes, a built-in classified template, and shared test fixtures. 4 phases, 10 tasks.

== Phase 1: Foundation — Test Fixtures and Renderer Changes

Set up shared test fixtures and modify the renderer to expose document attributes alongside HTML output.

* [x] TASK-001: Create shared test fixture AsciiDoc files [parallel]
+
Components:: Test fixtures (`tests/fixtures/`)
Stories:: US-006
Specs:: THM-024, THM-025
Description:: Create `tests/fixtures/` directory with: `minimal.adoc` (plain text), `with-mermaid.adoc` (Mermaid diagrams), `with-code.adoc` (syntax-highlighted code blocks), `with-includes/main.adoc` + `with-includes/chapter.adoc` (include directives), `with-metadata.adoc` (all conventional metadata attributes: classification, handling, distribution, retention, document-id, review-date, department).

* [x] TASK-002: Modify `src/render.js` to return document attributes [parallel]
+
Components:: AsciiDoc Renderer (`src/render.js`)
Stories:: US-003
Specs:: THM-013
Description:: Change `renderToHtml()` to use `asciidoctor.load()` + `document.convert()` instead of `asciidoctor.convert()`. Return `{ html, attributes }` where `attributes` is the object from `document.getAttributes()`. Update all callers (`src/commands/render.js`, `src/commands/watch.js`) to destructure the new return type. Ensure existing tests still pass (the HTML output is identical).

== Phase 2: Core — Theme Engine

Implement the theme engine module that applies CSS overrides, template wrapping, and metadata injection.

* [x] TASK-003: Implement `src/theme.js` — data attribute injection [sequential]
+
Components:: Theme Engine (`src/theme.js`)
Stories:: US-003
Specs:: THM-014
Description:: Create `src/theme.js` with `applyTheme(html, attributes, options)`. Start with Step 1: inject `data-*` attributes on the `<body>` tag for user-defined document attributes. Sanitise attribute names (lowercase, hyphens). Filter out internal Asciidoctor attributes (those starting with common internal prefixes like `doctype`, `outfilesuffix`, `filetype`, `backend`, etc.).

* [x] TASK-004: Implement CSS theme replacement [sequential]
+
Components:: Theme Engine (`src/theme.js`)
Stories:: US-001, US-005
Specs:: THM-001, THM-002, THM-021, THM-022, THM-023
Description:: Add Step 2 to `applyTheme()`: when `themePath` is provided, read the CSS file, resolve relative `url()` font references to base64 data URIs (relative to the CSS file's directory), and replace the default Asciidoctor `<style>` block in `<head>`. Preserve the highlight.js CSS block. Log a warning to stderr for missing font files and continue rendering.

* [x] TASK-005: Implement HTML template application [sequential]
+
Components:: Theme Engine (`src/theme.js`)
Stories:: US-002, US-003
Specs:: THM-007, THM-008, THM-009, THM-010, THM-013, THM-015
Description:: Add Step 3 to `applyTheme()`: when `templatePath` is provided, resolve the template (built-in name or file path), read it, substitute `{{attr}}` with HTML-escaped values, substitute `{{{attr}}}` and `{{{body}}}` with raw values, extract the `<body>` content from the enriched HTML for injection. Unset attributes become empty strings.

* [x] TASK-008: Create built-in classified template [parallel]

Components:: Built-in template assets (`assets/templates/classified/`)
