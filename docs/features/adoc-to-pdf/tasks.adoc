== Overview

Extend the adoc-to-pdf pipeline with Mermaid diagram rendering and source code syntax highlighting. Both capabilities use browser-side JavaScript injection into the existing Playwright/Chromium pipeline. 3 phases, 6 tasks.

== Phase 1: Dependencies and Enricher Module

Install new dependencies and create the HTML enricher module that injects mermaid.js and highlight.js into the rendered HTML.

* [x] TASK-008: Install mermaid and highlight.js dependencies [sequential]
+
Components:: package.json
Stories:: US-005, US-006
Specs:: PDF-014, PDF-019
Description:: Install `mermaid` and `highlight.js` as production dependencies. Verify licenses are permissive (MIT, BSD-3-Clause). Run `npm ls` to confirm no licensing violations.

* [x] TASK-009: Create the HTML enricher module [sequential]
+
Components:: src/enrich.js
Stories:: US-005, US-006
Specs:: PDF-014, PDF-015, PDF-016, PDF-017, PDF-018, PDF-019, PDF-020, PDF-021, PDF-022
Description:: Create `src/enrich.js` exporting `enrichHtml(html)`. At module load, read mermaid.min.js source from `node_modules/mermaid/dist/` and highlight.js core + github theme CSS from `node_modules/highlight.js/`. The function: (1) transforms Asciidoctor's `[source,mermaid]` output (`<code data-lang="mermaid">`) into `<pre class="mermaid">` elements, (2) injects mermaid.js with `mermaid.initialize({ startOnLoad: false })` and `mermaid.run()`, (3) injects highlight.js core + CSS theme + `hljs.highlightAll()`, (4) configures mermaid error handling to replace invalid blocks with styled error messages and emit `console.warn()`. Execution order: mermaid runs first, then highlight.js.

== Phase 2: Pipeline Integration

Wire the enricher into the CLI pipeline and update the printer to handle browser-side JS execution.

* [x] TASK-010: Integrate enricher into CLI pipeline [sequential]
+
Components:: src/cli.js, src/enrich.js
Stories:: US-005, US-006
Specs:: PDF-014, PDF-019
Description:: In the `render` command action handler, after `renderToHtml()` and before `printToPdf()`, call `enrichHtml(html)`. Pass the enriched HTML to the printer.

* [x] TASK-011: Update printer to capture console warnings [parallel]
+
Components:: src/print.js
Stories:: US-005
Specs:: PDF-017
Description:: Register a `page.on('console')` listener before `setContent()`. Filter for `warning` type messages and forward them to `process.stderr`. This captures mermaid's error warnings for invalid diagram syntax. Ensure `waitUntil: 'load'` still works correctly with the injected scripts (the enricher's scripts run during page load).
