== Overview

Replace `playwright` with `playwright-core` and add system browser detection so that proven-docs uses an existing Chromium-based browser on the host system instead of requiring a Playwright-managed browser download. 2 phases, 4 tasks.

== Phase 1: Browser Discovery Module

Create the browser discovery module and swap the dependency.

* [x] TASK-018: Create src/browser.js with discoverBrowser() [sequential]
+
Components:: src/browser.js (new)
Stories:: US-008
Specs:: PDF-028, PDF-029, PDF-030, PDF-031, PDF-032
Description:: Create a new module `src/browser.js` that exports `discoverBrowser()`. The function checks `BROWSER_PATH` env var first, then searches platform-specific well-known paths for Chrome, Edge, and Chromium in that preference order. On macOS, check application bundle paths with `fs.existsSync()`. On Linux, resolve binary names (`google-chrome-stable`, `google-chrome`, `microsoft-edge-stable`, `microsoft-edge`, `chromium-browser`, `chromium`) via PATH lookup. On Windows, expand `%PROGRAMFILES%`, `%PROGRAMFILES(X86)%`, and `%LOCALAPPDATA%` and check known paths with `fs.existsSync()`. Return the first match found. Throw a descriptive error if no browser is found, listing supported browsers and the BROWSER_PATH escape hatch.

* [x] TASK-019: Swap playwright to playwright-core in package.json [parallel]
+
Components:: package.json
Stories:: US-008
Specs:: PDF-033
Description:: Replace `"playwright"` with `"playwright-core"` in `dependencies`. Run `npm install` to update the lock file. The version range should match the current playwright version (^1.58.2). Verify the installed package provides the same `chromium` export.

== Phase 2: Integration

Wire browser discovery into the PDF printer.

* [x] TASK-020: Update src/print.js to use playwright-core and discoverBrowser [sequential]
+
Components:: src/print.js, src/browser.js
Stories:: US-001, US-008
Specs:: PDF-003, PDF-028, PDF-033
Description:: Change the import from `import { chromium } from 'playwright'` to `import { chromium } from 'playwright-core'`. Import `discoverBrowser` from `./browser.js`. At the start of `printToPdf()`, call `discoverBrowser()` to get the executable path. Pass it to `chromium.launch({ executablePath })`. All other code (page.setContent, addScriptTag, page.evaluate, page.pdf) remains unchanged.

* [x] TASK-021: Update existing tests for playwright-core compatibility [parallel]
+
Components:: tests/features/adoc-to-pdf/print.test.js
Stories:: US-001, US-008
Specs:: PDF-003, PDF-028
Description:: Existing print tests may import or mock `playwright`. Update any such references to `playwright-core`. Ensure existing tests pass with the new dependency. No new test files are needed here — `needs-tests` will generate browser discovery tests separately.
