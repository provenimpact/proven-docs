== Overview

Fix include directive resolution so that `include::` paths resolve relative to the document's directory, not the CLI's working directory. Affects render, validate, and info commands. 1 phase, 4 tasks.

== Phase 1: Include Resolution

Add `base_dir` to all Asciidoctor calls so includes resolve relative to the input file's directory.

* [x] TASK-014: Update renderToHtml to accept and pass base_dir [parallel]
+
Components:: src/render.js
Stories:: US-007
Specs:: PDF-023, PDF-024
Description:: Change `renderToHtml(source)` signature to `renderToHtml(source, baseDir)`. When `baseDir` is provided, add `base_dir: baseDir` to the Asciidoctor `convert()` options object. When omitted, do not set `base_dir` (backward compatible).

* [x] TASK-015: Pass base_dir from render command [parallel]
+
Components:: src/commands/render.js
Stories:: US-007
Specs:: PDF-023, PDF-024
Description:: In the render command handler, after resolving `inputPath`, derive `baseDir` as `path.dirname(inputPath)`. Pass `baseDir` as the second argument to `renderToHtml(source, baseDir)`.

* [x] TASK-016: Pass base_dir from validate command [parallel]
+
Components:: src/commands/validate.js
Stories:: US-007
Specs:: PDF-023, PDF-025
Description:: In the validate command handler, add `base_dir: path.dirname(filePath)` to the options object passed to `asciidoctor.load()`.

* [x] TASK-017: Pass base_dir from info command [parallel]
+
Components:: src/commands/info.js
Stories:: US-007
Specs:: PDF-023, PDF-026
Description:: In the info command handler, add `base_dir: path.dirname(filePath)` to the options object passed to `asciidoctor.load()`.
